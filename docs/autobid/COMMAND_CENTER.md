# CAIgraph — командный центр

Откройте ярлык **CAIgraph - Командный центр** на рабочем столе или в папке Bid_master.
Он запускает приложение без консольного окна и открывает http://127.0.0.1:8765/.
Повторный запуск открывает уже работающий центр. Интернет для открытия сохранённой базы не нужен.

## Возможности
- Лента реальных объявлений FL.ru: название, описание, бюджет, число откликов, ссылка.
- Поиск по тексту и форматам; фильтры источника, заказов/вакансий и указанного бюджета.
- Карточка с полным сохранённым описанием либо явно помеченным фрагментом из ленты.
- «Проверить сейчас» запускает ограниченный обход: две страницы разделов и до десяти карточек.
- Мониторинг каждые 30 или 60 минут. По умолчанию выключен; настройка сохраняется.
  После запуска центра или включения мониторинга первая плановая проверка выполняется через выбранный интервал.
  Чтобы проверить сразу, нажмите «Проверить сейчас».
- «Выключить центр» останавливает сервер и плановые проверки. При текущем обходе завершится
  уже начатый сетевой запрос, сохранится частичный отчёт, затем процесс закроется.
  Простое закрытие вкладки не останавливает приложение.
- Мониторинг работает при запущенном центре и бодрствующем компьютере. Автозапуск Windows не устанавливается.

Для заказа нажмите «Подготовить отклик», отредактируйте текст и нажмите «Одобрить текст».
Затем «Откликнуться» поставит утверждённую версию в очередь dot. Редактирование отменяет одобрение.
Пока агент не забрал отклик, его можно снять с отправки. Состояние «Отправлено» появляется только
после записи проверенного результата агентом. Автоматического браузерного отправителя внутри UI нет.
Протокол подключения: [AGENT_PROTOCOL.md](AGENT_PROTOCOL.md).
Встроенный сборщик работает с FL.ru; остальные источники принимают наблюдения через CLI. Неизвестное число откликов отличается от нуля.
Опубликованные бюджеты — данные заказчиков, а не подтверждённые выплаты.

## Ярлык и запуск
Установщик создаёт одинаковый ярлык в папке проекта и на рабочем столе:
~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Install-CommandCenterShortcut.ps1
~~~

На этом компьютере используется среда:
D:\DrawingAI_runs\bid-master-source-access-2026-11-02\venv

Данные, отчёты, профили браузера и журналы остаются в:
D:\DrawingAI_runs\bid-master-source-access-2026-11-02

Черновики, версии одобрений и журнал переходов: command-center/reviews.sqlite3.
Настройки центра: command-center/settings.json. Журнал: command-center/server.log
(до трёх файлов по 1 МБ). DISCOVERY_DATA_ROOT меняет каталог данных; в Windows допускается
только диск D:. CAIGRAPH_PYTHON задаёт путь к уже установленному python.exe/pythonw.exe.

Прямой запуск из корня исходников:
~~~powershell
& 'D:\DrawingAI_runs\bid-master-source-access-2026-11-02\venv\Scripts\python.exe' -B -m autobid.command_center
~~~
Параметры: --data-root PATH, --port 8765, --no-browser.
Если порт занят другим приложением либо другим хранилищем CAIgraph, запуск сообщает об ошибке.
Существующий процесс не завершается.

На новом компьютере сначала подготовьте окружение на D: по DISCOVERY.md, установите пакет
с дополнениями discovery. Интерфейс дополнительных библиотек не требует.
Локальный сервер слушает только 127.0.0.1; он не предназначен для публикации в сети.

## Проверка интерфейса
python -B scripts/Check-CommandCenterUI.py --data-root D:\DrawingAI_runs\caigraph-ui-test
Нужны Playwright, установленный Edge и установленный пакет проекта (либо PYTHONPATH к корню).
Проверка поднимает свой локальный сервер и тестовую базу, не меняет рабочие заказы.
Она проверяет редактирование, одобрение, очередь, конфликт вкладок, мобильный экран,
ошибки мониторинга и восстановления связи. Реальных сообщений не отправляет.
