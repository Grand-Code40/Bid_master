# Сбор CAD-заказов — первый этап CAIgraph

Новый модуль `autobid.discovery` читает объявления, сохраняет историю наблюдений и обновляет карточки. Он не импортирует сервис отправки ставок. Основной бренд — CAIgraph; альтернативные публичные имена: Константин Аистов и Casei.

## Что работает

| Источник | Состояние реализации |
|---|---|
| FL.ru, Инжиниринг и 3D Графика | HTTP и отдельный браузерный профиль; списки и детали; цена, счётчик откликов, статус |
| Freelance.ru | В реестре; адаптер ещё не реализован |
| Telegram | В реестре; доступ и условия использования требуют отдельной проверки |
| Kwork | В реестре; автоматизированный доступ ограничен правилами площадки |

Проверено 2026-11-02: первый обход двух страниц и трёх деталей сохранил 60 объявлений; повторный обход — 0 новых, 1 обновление, 59 без изменений. Это ограниченная наблюдённая выборка, не размер всего рынка. Браузерный способ дважды прочитал по 30 карточек после закрытия и повторного открытия выделенного профиля Edge. Авторизованный вход и реальные регистрации ещё не проверены.

Полная панель управления, отклики, переписка и поиск новых площадок по всему интернету относятся к следующим этапам. Текущий результат — команды, SQLite, JSON и читаемый Markdown-отчёт. Сложные CAD-задачи автоматически не исключаются; метки помогают просмотру, не обещают выполнимость.

## Запуск в текущей рабочей копии

Все команды ниже выполняются из рабочей копии на D:. Подготовленное окружение переиспользует существующие зависимости AutoBid из исходного проекта; новые библиотеки установлены на D:. Для независимой установки используйте следующий раздел.

```powershell
Set-Location -LiteralPath 'D:\DrawingAI_runs\bid-master-source-access-2026-11-02\worktree'
$python = 'D:\DrawingAI_runs\bid-master-source-access-2026-11-02\venv\Scripts\python.exe'
& $python -B -m autobid.discovery.cli sources
& $python -B -m autobid.discovery.cli scan --max-pages 2 --max-details 10
& $python -B -m autobid.discovery.cli report
```

Последний отчёт: `D:\DrawingAI_runs\bid-master-source-access-2026-11-02\reports\latest.md`; данные: `latest.json`, база: `discovery.sqlite3`. Команда `report` читает сохранённое состояние, не делает нового сетевого обхода.

```powershell
# Явно выбрать браузерный способ вместо HTTP:
& $python -B -m autobid.discovery.cli --transport browser --browser-channel msedge scan --max-pages 1 --max-details 2
# Одна конкретная карточка поддерживаемого источника:
& $python -B -m autobid.discovery.cli import-url 'https://www.fl.ru/projects/5527616/izgotovlenie-chertejey-pochtovogo-yaschika-dlya-jilogo-kompleksa.html'
# Работает в этом терминале до Ctrl+C; сам по себе не устанавливает службу:
& $python -B -m autobid.discovery.cli watch --interval-seconds 3600 --max-pages 2 --max-details 10
```

По умолчанию выполняется не более 2 страниц списков и 10 деталей за обход. Лимит страниц общий; сначала проверяются настроенные разделы, затем следующие страницы. Не все найденные карточки получают полное описание при таком лимите. Для интервала 30 минут укажите 1800. Компьютер и терминал должны оставаться включёнными. Watch в рамках разработки не запускался. При Ctrl+C во время обхода сохраняются частичный отчёт и причина interrupted; код выхода — 130. Время предыдущего успешного доступа не подменяется временем прерывания.

## Установка в другом окружении

Из корня репозитория, с существующим диском D:

```powershell
$dataRoot = 'D:\DrawingAI_runs\bid-master-source-access-2026-11-02'
New-Item -ItemType Directory -Force -Path "$dataRoot\tmp" | Out-Null
$env:TEMP = "$dataRoot\tmp"
$env:TMP = $env:TEMP
$env:PIP_CACHE_DIR = "$dataRoot\pip-cache"
$env:PLAYWRIGHT_BROWSERS_PATH = "$dataRoot\browsers"
py -3.11 -m venv "$dataRoot\venv"
& "$dataRoot\venv\Scripts\python.exe" -m pip install -e '.[test,discovery,browser]'
# Для Chromium вместо уже установленного Edge:
& "$dataRoot\venv\Scripts\python.exe" -m playwright install chromium
```

Windows-команды по умолчанию используют установленный Edge. Python API `BrowserSession` принимает `channel='msedge'`; без channel требуется установленный Chromium. Для другого каталога данных перед подкомандой задайте `--data-root D:\DrawingAI_runs\...` или `DISCOVERY_DATA_ROOT`. На Windows пути на других дисках отклоняются, на C: нет резервного каталога. TEMP, TMP и кэш браузерных бинарников направляются в каталог данных на время работы.

## Подключение аккаунта

Для публичного чтения аккаунт не нужен. `connect fl` открывает отдельный профиль Edge для существующего аккаунта; `connect fl --register` — форму регистрации. Сначала используйте имеющийся аккаунт, чтобы не создавать дубликаты.

```powershell
# Email можно задать локально через переменную среды DISCOVERY_EMAIL.
# Не передавайте пароли и SMS-коды в параметры команд.
& $python -B -m autobid.discovery.cli connect fl
# Только если нужен новый аккаунт:
& $python -B -m autobid.discovery.cli connect fl --register
```

Известный email подставляется в наблюдённое поле формы. Текущие формы FL.ru не запрашивают публичное имя на первом шаге. После ручного шага нажмите Enter в терминале для повторной проверки, q — сохранить этап и закрыть браузер. Поддерживаются этапы формы, email, SMS, CAPTCHA, условий, входа и проверки доступа. Форма не отправляется автоматически. Пароль, принятие условий и CAPTCHA выполняются владельцем в открытом браузере; менеджер паролей и чтение писем рабочего ящика в этот CLI пока не подключены.

Локальный браузерный профиль сохраняется в `profiles\fl`; это чувствительные данные сессии, не добавляйте его в Git и не передавайте другим. Профиль текущего ChatGPT-браузера не копируется. При повторном запуске используется тот же выделенный профиль, а сохранённый этап показывается в `sources`. Наличие записи этапа не заменяет проверку фактического входа. Эвристика признака выхода из аккаунта реализована, но реальный авторизованный сценарий ещё не проверен.

## Значение данных и ограничения

- Бюджет — опубликованная цена, не фактическая оплата. Валюты, разовые заказы, вакансии и конкурсы разделены. Неизвестное значение — null; видимое «нет ответов» — 0.
- Каждое наблюдение сохраняется с датой и происхождением полей. Повторный обход обновляет запись по паре источник/ID. Более старые наблюдения не откатывают новые поля.
- Короткая аннотация из списка не стирает ранее сохранённое полное описание. Числа, статус и бюджет обновляются независимо. При сбое страницы деталей сохраняется прежний полный текст.
- Даты без подтверждённого часового пояса и относительные даты сохраняются исходным текстом. Точное published_at остаётся неизвестным.
- Сборщик сохраняет текст объявлений, но не скачивает приложенные чертежи и не отправляет их внешним CAD- или ИИ-инструментам.
- Страница входа, CAPTCHA, 403/429 и неожиданная разметка дают отдельное состояние ошибки/доступа. Они не считаются пустой успешной выборкой. Попытки HTTP ограничены.
- Поле last_success показывает последний успешный доступ. Ошибка нового обхода его не стирает. Ограничение страниц и ошибки деталей отмечаются в отчёте.
- Блокировка `.discovery.lock` не допускает одновременное использование одной базы/профиля командами. После завершения или аварии процесса ОС освобождает блокировку. Сам файл можно оставить; удаление файла не является способом снять живую блокировку.
- SQLite и история пока не имеют автоматического срока хранения. Следите за размером каталога данных; межплощадочные дубли автоматически не объединяются.

## Проверки

```powershell
& $python -B -m pytest -q -p no:cacheprovider --basetemp 'D:\DrawingAI_runs\bid-master-source-access-2026-11-02\pytest-full'
```

Финальная проверка: 93 теста (39 прежних AutoBid и 54 проверки сборщика). Два замечания независимого ревью воспроизведены тестами и исправлены. Новые проверки покрывают повторное чтение, потерю полей, данные полной карточки, ошибки доступа, неподдерживаемые ссылки, разделение бюджетов, блокировки и остановку watch.

Временные `pytest-*`, `tmp`, `pip-cache` и `observed` можно удалить после завершения работающих процессов. Для дальнейшего запуска нужны рабочая копия, окружение, база и профиль. Размеры созданных данных сообщаются при сдаче.

Официальные справочники библиотек: [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/bs4/doc/) и [Playwright: профили](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context), [размещение браузеров](https://playwright.dev/python/docs/browsers).
