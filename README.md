# CAIgraph / Bid_master

Командный центр для поиска CAD-заказов и проверки откликов.

- Лента заказов: описание, бюджет, число откликов, исходная ссылка.
- Редактор: подготовить черновик → изменить → одобрить → поставить в очередь для агента.
- Сохранение черновиков и одобрений в SQLite. Правка снимает одобрение; неизвестный результат отправки блокирует повтор.
- Встроенный сборщик FL.ru с интервалом 30 или 60 минут.
- CLI для облачного dot: импорт наблюдений из других источников, получение очереди, фиксация результата.

**Начать передачу облачному dot:** [CLOUD_HANDOFF.md](CLOUD_HANDOFF.md).
**Протокол агента и формат данных:** [AGENT_PROTOCOL.md](docs/autobid/AGENT_PROTOCOL.md).
**Windows и ярлык запуска:** [COMMAND_CENTER.md](docs/autobid/COMMAND_CENTER.md).

## Быстрый запуск на Linux / облачном компьютере

Python 3.11 или новее. Из корня клонированного репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[discovery]'
export DISCOVERY_DATA_ROOT="$HOME/caigraph-data"
python -m autobid.command_center --no-browser
```

Панель: http://127.0.0.1:8765/ на том же компьютере. Для постоянного доступа с другого устройства нужен отдельный этап хостинга/защищённого доступа.

На Windows данные, окружение, кэши и временные файлы этого проекта размещаются на диске D:. Текущий ярлык **CAIgraph — Командный центр** использует scripts/Start-CommandCenter.ps1.

## Что подключено

FL.ru читается встроенным HTTP-сборщиком. Freelance.ru, Telegram, Kwork и Freelancer.com принимают наблюдения через CLI; это ещё не автоматически работающие браузерные сборщики. Встроенного LLM в новом центре нет: первый черновик формируется из полей заказа, персонализацию может выполнить dot.

Нажатие «Откликнуться» создаёт очередь. Сам CLI не нажимает отправку на сайтах: подключённый агент выполняет её в своём браузере и записывает проверенный результат. Облачный агент, аккаунты, расписание dot и хостинг не создаются установкой проекта. Сбор ответов заказчиков в отдельный inbox пока не реализован.

## Проверка

```bash
python -m pip install -e '.[discovery,test]'
python -m pytest -q
```

На Windows используйте --basetemp с абсолютным путём на D:. UI-проверка использует Playwright и установленный Edge: scripts/Check-CommandCenterUI.py --data-root <отдельный тестовый каталог>. Она работает только с тестовой базой и не отправляет сообщений.

Старый независимый конвейер официального API Freelancer описан в [docs/autobid/README.md](docs/autobid/README.md). Новый центр его не запускает. Его GitHub Actions расписание выключено, пока явно не задана переменная AUTOBID_SCHEDULE_ENABLED=true.
