# CAIgraph interface

Working UI for an owner reviewing CAD orders. The user rejected both the old green, overly rounded dashboard and a plain admin-table treatment.

Reference: [Linear's interface redesign](https://linear.app/changelog/2024-03-20-new-linear-ui) and [Inbox](https://linear.app/docs/inbox). Use their hierarchy, quiet neutral surfaces and focused task editing as references, not their branding or assets.

Visual system:
- Narrow graphite navigation rail with a custom geometric CAIgraph mark.
- Cool silver page, white work surface, subtle violet selection and action accents.
- One system sans, strong 30px page title, 17px order titles, aligned budget column.
- Consistent authored SVG icons; no emoji, decorative charts or marketing hero.
- Full-width order rows with one consistent “Ответить” action; a centered native modal dialog with clear approval/queue state.
- Compact controls and secondary metadata; readable main task text, visible focus, a scrollable mobile dialog with a fixed close button and action footer.
- Only real orders, budgets, counts and connection states. Initial drafts and agent queue are labelled honestly.

Impeccable Operate/distill/craft-floor guidance applied directly from its official repository. Local context helper was unavailable.
