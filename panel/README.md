# CAIgraph: очищенные исходники Sites v23

База: `f0bb19a52bc92296ff13c9ab41742aedf617b0e3`. По контексту передачи это deployed Sites v23. Живой сервис в ходе упаковки не проверялся. Это **очищенная производная копия**, а не побайтовый backup production и не готовый deployment archive.

## Что передано

Код Worker/MCP/API, веб-интерфейс, схемы и декларативные Drizzle migrations, сборка и синтетические тесты. В `SANITIZATION.json` перечислены изменения очистки. Конкретные наблюдавшиеся заказы/посты заменены синтетическими идентификаторами; это не новые реальные evidence. Их нельзя открывать или импортировать как реальные заказы. Публичные имена источников/каналов и ограничения сохранены как часть программного каталога.

Не включены рабочие D1/SQLite базы, письма пользователя, реальные заказы и ответы, сессии, профили браузера, ключи, токены, пароли, `.env`, git history, оперативные отчёты и deployment identifiers. Адреса `example.test` и очевидные dummy secrets в negative tests исключительно синтетические. Пример `.openai/hosting.json` имеет `project_id: null`: публикация намеренно заблокирована до явной настройки.

## Проверить локально

Node.js 24.22.1 использовался при проверке. Базовая сборка и тесты не требуют npm install.

```sh
node scripts/build-local.mjs
node --import ./scripts/offline-guard.mjs --test
USE_GENERATED_MIGRATIONS=1 node --import ./scripts/offline-guard.mjs --test
```

Тесты используют SQLite `:memory:`, синтетический DOM и отключённую сеть. `scripts/dev-preview.mjs` предназначен исключительно для изолированного QA, подставляет фиктивного владельца и теперь слушает только localhost. Никогда не публикуйте QA preview и не используйте его для авторизации production.

## Как безопасно применить будущий diff

1. Не заменяйте актуальный сайт старым GitHub `main`. Не делайте reset, force push, массовое копирование архива поверх production или автоматический deploy.
2. Сверьте фактический production SHA и схему. Для изучения создайте отдельную локальную рабочую копию из этого архива. Git history намеренно отсутствует. Изменения очистки не переносите обратно на живую базу как функциональное исправление.
3. Измените нужные исходники в отдельной локальной ветке. Просмотрите diff вручную; исключите `.openai`, параметры доступа, каталожную синтетику и рабочие данные. Сначала прогоните оба набора тестов на синтетической БД.
4. До любой разрешённой миграции сделайте защищённый backup вне этого пакета и проверяемый план восстановления. Не выгружайте пользовательские данные в Codex или GitHub. Не выполняйте повторно начальные migrations на уже существующей схеме: сравните журнал migrations, применяйте только недостающие согласованные изменения.
5. Сохраните существующие D1 binding, owner identity, runtime secrets и все строки orders/reviews/mail/history. Не удаляйте таблицы, не пересоздавайте БД, не меняйте подключение на пустую БД. Публикация и миграция требуют отдельного разрешения владельца; этот архив их не выполняет.

## Ограничения источников и отправки

- Weblancer на паузе. Заявление пользователя об условиях/разрешении поддержки не проверено независимо; не считать его разрешением на автоматизацию и не возобновлять работу без проверки и разрешения.
- FL RSS запрещён robots: не запрашивать RSS и не обходить запрет. Наличие URL в валидаторе/историческом коде не является разрешением на fetch.
- Не включать автоматическую отправку, сбор данных или обход правил площадок. Код учёта/валидации не равен разрешению действовать.
- Эксперимент browser dispatcher (исторический `b8e1b5d`) **НЕ production**, в этом архиве отсутствует и им не заменяет v23. На момент передачи отдельная проверка guard для legacy alias не завершена. Не включать его автоматически и не представлять как надёжную browser-доставку.

## Проверки и предел уверенности

См. `QA.md`, `AUDIT.json`, `MANIFEST.sha256`. Проверка пакета не является гарантией безопасности приложения или разрешением к публикации. В одном повторном прогоне выявлен нестабильный тест конкурентной отмены/подтверждения; он явно отражён в QA. Рабочее поведение этим пакетом не исправлялось.
