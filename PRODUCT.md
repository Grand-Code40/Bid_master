# CAIgraph command center
Audience: owner of a CAD automation service, reviewing a stream of freelance orders.
Primary task: choose an order, review/edit a proposal, approve it and queue it for a connected agent.
Sources are untrusted observations, budgets and bid counts may be unknown. Unknown is not zero.
Owner decides feasibility and pricing. No workload reservation. Approval is per proposal revision.
Current native monitor: FL.ru HTTP collector. Cloud dot integration uses a local CLI and must be set up on the cloud computer.
